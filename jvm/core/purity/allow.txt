#
#   <path> <rule> <why, in words>
#
# <path> is a source file relative to jvm/ (core/<module>/src/main/java/...); * matches within a name, ** across
# directories. <rule> is a rule id from rules.txt, or * for every rule (only for a file still to be cut). The reason is
# required. An entry that no longer matches any finding fails the check, so the list only shrinks as seams land.
